# Information Delivery（Round 9）

## 投放方式

document / dialogue / observation / professional procedure / conflict / mistake / absence / contradiction / consequence / memory / public information。悬疑小说最容易写成材料说明会。

## 诊断

INFORMATION_DUMP / PROFESSIONAL_EXPOSITION_DUMP / SOCIAL_COMMENTARY_DUMP / MYSTERY_EXPLANATION_DUMP / CLUE_DELIVERY_TOO_EXPLICIT（“这就是关键证据”）。

## 信息差

支持 reader knows > heroine / heroine knows > reader / reader == heroine（复用 audience knowledge）；不是任何信息都必须藏，早告诉读者有时反而制造 tension。

## InformationDeliveryPlan

informationUnit / readerBefore / heroineBefore / deliveryMode / surfacePurpose / immediateInterpretation / hiddenImplication / strategicEffect（仅重要信息；hiddenImplication 作者私有）。
