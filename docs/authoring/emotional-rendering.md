# Emotional Rendering（Round 9）

## 四层

felt emotion → shown behavior → decision effect → relationship effect。不要求每个情绪都有身体动作。

## 检查

- EMOTION_LABEL_WITHOUT_EFFECT：连续“她愤怒/她悲伤/她失望/她震惊”但行为无变化；
- EMOTION_WITHOUT_DECISION_EFFECT：high-value 场景强情绪 beat 无任何 choice/tactic/relationship behavior 作用；
- ACTION_OVEREXPLAINED_BY_INTERIORITY：动作后总是心理解释（“她这么做，是因为她终于意识到……”）。

## story-bearing emotion

“她害怕”= 她没有立刻提交材料，先复制了一份到个人取证盘。情绪通过选择兑现。
