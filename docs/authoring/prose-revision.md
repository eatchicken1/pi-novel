# Prose Revision（Round 9）

## Scoped 范围

默认 Beat → Scene → Event → Chapter；对话不自然不得整章重写。revise_chapter goal：scope（beat/scene/event/chapter）+ proseGoal（tighten-scene / increase-subtext / reduce-exposition / strengthen-opposition / restore-voice / dramatize-professional-detail / strengthen-emotional-action / fix-dialogue-specificity / improve-scene-turn）+ sceneIds。

## Fact Preservation

Prose revision 禁止偷偷改变：Mystery truth / Clue factual content / Professional action authority / Marriage state / Harm-Repair state / Unified Event consequence。
- 修订稿删除事件 delta 要求的关键引用（clue/claim/harm/repair/action/observation id）→ PROSE_REVISION_CHANGED_FACT（block）；需要改事实请升级为 planning revision；
- 旧 semantic/realization 记录按 hash 自然 stale。

draft scene → mechanical → semantic → repairability（沿用 Round 8 分类：AUTO_REPAIRABLE / MODEL_SCENE_REWRITE_REQUIRED / PLANNING_REVISION_REQUIRED，不建平行分类体系）。
