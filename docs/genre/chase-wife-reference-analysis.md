## 二、共同情节骨架

### 1. 开场不是交代，而是可见的偏爱证据

高频开场结构是：一个具体物件或行动暴露关系排序，例如礼物、座位、婚纱照、手机、琴房权限、医院决定。随后立刻出现一个“解释”，对方把越界包装成体谅、友情、苦衷、性格差异或女主太敏感。

有效点不在于“男方出轨”四个字，而在于读者能立刻看到：女主付出了什么、别人拿走了什么、男方如何要求她继续理解。

### 2. 前段用重复伤口完成累积，而不是只靠一次反转

多篇会把同一种不公换成三至五个生活细节：每次都不是致命事件，却共同证明女主永远排在第二位。数字、重复物件和固定句式是压迫感的计量器，例如第 N 次缺席、99 次道歉、一直“先让别人选”。

### 3. 付费卡点是“女主停止索取”

约 3,000—4,000 字附近的真正转折通常不是男方突然认错，而是女主完成一个不可逆动作：取消登记、离开婚礼、出售事业、公开证据、签离婚协议、停止解释或选择另一个人生方向。

卡点前的任务是把“她为什么终于不再等”写到读者不需要额外解释。

### 4. 中段把私人伤害转成公共后果

6,000—8,000 字附近常见的放大器包括：婚礼现场、直播、公司舆论、家族宴会、医院、法院、发布会和公开演出。私人关系中的双标被第三方看见后，男方不能再用“你误会了”恢复原状。

### 5. 大高潮不是单纯打脸，而是选择权彻底易手

男方通常在最后阶段才真正意识到失去，但他的悔恨不能自动换回关系。大高潮应同时完成三件事：女主明确拒绝旧关系、旧关系承担现实代价、读者看到女主已经拥有不依赖男方的新生活。

## 三、情绪曲线

常见曲线不是简单的“虐—爽”，而是叠加变化：

```text
熟悉/期待
→ 发现异样
→ 惊讶与自我怀疑
→ 被否认、羞辱或要求体谅
→ 悲伤、愤怒、厌恶叠加
→ 冷静决定退出
→ 行动带来的掌控感
→ 公开后果和迟来的追悔
→ 平静、余痛或新生活的安全感
```

有效的虐点往往是“价值被排序”，不是单一背叛：女主的时间、身体、劳动、尊严、事业、孩子、家庭位置或长期信任被当成可无限透支的资源。有效的爽点来自她重新拥有这些资源的处置权。

## 四、人物与对立关系

- 女主：前期可以隐忍，但必须有清晰的核心价值和不可触碰的底线；后期的冷静行动要能回溯到前期积累。
- 男主/前夫：不是纯粹恶人也不能靠一句“我有苦衷”洗白。他的核心缺陷通常是把女主的稳定当成不会消失，把边界问题解释成女主不够大方。
- 第三者或家人：应推动选择和暴露，不只是负责挑衅。她/他们要有自己的利益、误判或恐惧，否则冲突会像机关。
- 新伴侣：主要功能是提供尊重、稳定和新生活的验证，不应成为替女主完成全部复仇的工具。

## 五、追妻文专属创作约束

1. “追妻”不等于“必须复合”；默认结局是女主拥有拒绝权。
2. 男方追悔必须通过行动、损失和持续改变体现，不能只写哭、下跪和回忆。
3. 女主的反击应有现实载体：证据、合同、财产、职业、社交关系、法律或公开场合。
4. 不复制参考文的触发器组合，例如同样的婚礼、同样的第三者身份、同样的公开视频和同样的结婚证反转。
5. 每个虐点都要带来信息、关系、风险或资源变化；每个爽点都要兑现前文承诺。
6. 结尾至少回答：女主失去什么、重新获得什么、男方承担什么、旧关系是否仍有未处理的余痛。

## 六、可执行短篇双轨模板

适合 8,000—12,000 字、12—24 个 beat；不要求所有事件使用相同长度，也不把付费卡点当成故事阶段：

女主轨：

```text

→ recognition
→ micro-withdrawal
→ boundary-test
→ irreversible-exit
→ self-rebuild
→ final-boundary
```

男方轨：

```text
entitlement
→ loss-of-control
→ wrong-pursuit
→ real-consequence
→ recognition
→ respect-or-failure
```

事件使用 `paywallHook: true` 标记商业卡点；它可以附着在证据、退出、公开后果或关系转折上，不得作为独立阶段强行插入。男方轨可在女主退出后立即开始，并与女主新生活交叉；`recognition` 必须发生在至少一个 `real-consequence` 之后。

## 七、批注案例带来的修正

用户补充的《岁岁无君亦无晴》批注 PDF 说明，之前的拆解仍停留在“阶段骨架”，没有拆到可直接用于写作的微事件层。新增拆解要求如下：

### 1. 先拆引言，再拆事件

开头引言不是背景，也不是完整梗概，而是用一个具体异常事实同时完成关系位置、女主当下认知、信息差和下一场冲突的入口。引言结束后必须马上进入一个可见动作或对话冲突。

### 2. 每个事件都要写功能

参考批注把正文拆成连续事件，并为每个事件说明其功能：引出人物、暴露关系、承接前文、加深伤害、给女主高光、完成小反击、转移主动权或制造付费钩子。今后不再只记录“发生了什么”，还必须记录：

```text
事件内容
事件功能
主动方与反应方
双方知识边界
女主心理和身体反应
男方/第三人的辩解或行动
前文承接与后文铺垫
读者释放点和下一钩子
```

### 3. 情绪要通过动作递进

批注案例的情绪不是连续形容“痛苦”，而是由偷听、停顿、失手、回避、试探、质问、强撑、离开等动作推动。女主每次反应都要比上一次更接近决断；男方则要区分“害怕失去控制”和“真正理解伤害”。

### 4. 章节不能只有一个大场景

短篇按功能使用 60—180、100—250、220—450 或 450—850 字的微事件，每章使用 3—6 个事件。第一事件必须把引言和即时冲突合并，前 1,500 字完成关系结构和至少两次反应变化，避免长篇回忆、环境和心理独白拖慢开局。

### 5. 本案例的抽象推进链

```text
引言抛信息差
→ 支开女主并让她听见秘密
→ 表面照常相处，细节持续泄露偏爱
→ 回忆女主曾经的高光，反衬当前背叛
→ 女主主动取证并撞破关系
→ 对方在现场护住第三人，冲突达到最高点
→ 女主取消婚姻/清空生活/离开
→ 公共场合曝光和社会后果
→ 男方从失控转入追悔
→ 时间跳跃展示女主新生活
→ 旧关系重现，女主完成最后边界
```

该链条只用于理解信息释放、情绪叠加和主动权转移，不用于复制人物身份、职业、关系组合、事件细节或表达方式。
