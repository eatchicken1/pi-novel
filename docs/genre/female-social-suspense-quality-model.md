# 女性社会派悬疑 Quality Model（Round 6）

## 质量分层

1. 结构正确（error 门禁）：引用完整、权限闭合、公平性成立、兑现锚点真实；
2. 类型成立（warning 诊断）：社会机制进因果链、职业不可替换、婚姻有历史、悬念有升级、乐章有变化；
3. 商业可读（warning 诊断）：开篇快、前段有成本、中点有重释、结局有余震、章节有向前的压力。

## 诚实原则

- 确定性 checker 只输出 error/warning 与统计（碰撞数、重复指纹、引擎覆盖），不输出评分；
- 模型评审（check_vertical_story_quality）只有 verdict（strong/workable/weak），没有数字分数；
- 每条 finding 必须带可核验的结构引用（eventIds / professionalActionIds / marriageRefs / clueIds / harmIds / patternIds / mechanismIds / dilemmaIds），引用不存在即报错。
