# 追妻文市场定义与写作方法研究

研究时间：2026-07-16

## 研究结论

“追妻文”或“追妻火葬场”更适合作为一种关系与情绪机制标签，而不是固定世界观、职业设定或唯一结局。它的最低承诺是：

```text
关系中的一方长期处于情感/资源低位
→ 另一方做出具体且可追责的伤害选择
→ 低位方心死、退出或夺回主动权
→ 高位方在失去后追悔并承担代价
→ 结局决定是否复合、换伴侣、独立生活或保留余痛
```

市场标签本身允许多种组合。晋江作品页面会把“追爱火葬场”和情有独钟、破镜重圆等标签并列；番茄作品简介也会把“追夫火葬场”和“先虐后爽”等卖点并列。因此，“追妻文”不能被程序默认成必须复合，也不能被提示词压缩成“男方下跪后女主回头”。

## 市场上的核心阅读承诺

### 1. 前期要让读者迅速判定谁在失去什么

成熟的开篇不会先交代完整背景，而是用一个具体行为让关系排序可见：缺席、替别人做决定、把女主的资源让出去、对第三人开放特权、公开维护别人而牺牲女主等。读者需要马上知道：女主失去的是时间、尊严、身体、事业、家庭位置、信任还是选择权。

### 2. 中段的关键不是“真相出现”，而是“女主不再索取”

真相揭露只提供认知，真正改变故事方向的是女主的主动选择：取消婚约、签协议、搬离、转职、公开证据、切断资源或拒绝解释。她的退出必须造成新事实，不能只是口头说分手后继续等待。

### 3. 后段的爽点是权力和认知反转

男方先经历失控，再逐渐理解自己反复做过的选择；公共后果、事业损失、关系崩解或法律代价把私人伤害外化。男方追悔是情节线，女主的新生活和边界才是结局线，两者不能互相替代。

### 4. 结局存在不同市场分型

- 复合型：男方持续改变，女主在新的条件下重新选择关系；
- 破镜不重圆型：女主拒绝复合，男方承担长期后果；
- 换伴侣型：新关系验证女主已经拥有平等、稳定和被尊重的生活；
- 独立收束型：女主不以新恋情证明成长，事业/家庭/自我秩序完成闭环。

提示词应先让作者选择结局分型，再设计追悔强度，不能先写“火葬场”再临时决定女主是否原谅。可执行结局契约中的映射：复合型 → earned-reunion；破镜不重圆型 → no-reunion；换伴侣型 → no-reunion（新关系通过 self-rebuild 事件验证独立未来）；独立收束型 → no-reunion 或 open-ending。

## 可复用的成熟结构方法

### 1. 节拍作为地标，不作为公式

Save the Cat! 的官方方法把 Opening Image、Catalyst、Debate、Break into Two、Midpoint、All Is Lost 和 Finale 等视为结构地标，用于追踪节奏、冲突和人物变化；其官方说明也强调这些是叙事标记，不是僵硬的页数规定。对追妻文的适配是：

| 通用地标 | 追妻文适配 |
| --- | --- |
| Opening Image | 女主仍相信关系正常，或正在替对方维护体面 |
| Catalyst | 第一个可验证的偏爱/越界证据 |
| Debate | 女主试图解释、确认或继续体谅 |
| Break into Two | 女主开始取证、设边界或准备退出 |
| Midpoint | 关系真相或伤害规模被重新定义 |
| All Is Lost | 女主确认旧关系不可能恢复，完成不可逆退出 |
| Finale | 新生活与旧关系后果同时落地 |

### 2. 每个场景必须发生价值变化

Story Grid 的场景方法要求识别场景开始和结束时的价值、极性变化及具体转折点；一个场景如果没有价值变化，故事就会停滞。其场景分析还把事件、渐进复杂化、危机、选择和结果作为可检查的组成部分。

因此，追妻文事件地图不能只写“发生了什么”，还要写：

```text
开始时女主相信什么/拥有什么
对方采取了什么策略
策略如何失败或暴露新信息
女主面对什么代价作出什么选择
结束时关系、知识、资源或风险发生了什么改变
```

### 3. 连续的反转方式要变化

不能连续十个事件都靠“发现新证据”推进。事件应交替使用：

```text
行动越界 → 对话辩解 → 物件/地点泄露 → 女主主动试探
→ 回忆重新解释 → 公开场合暴露 → 对方失控行动 → 新生活对照
```

这能避免“证据堆积但剧情不动”。

## 本项目的专属实现原则

以下是结合用户提供的批注 PDF、项目参考文本和上述成熟方法得出的工程化规则：

1. 第一章必须有开篇引言，但引言不是摘要；它要包含关系位置、异常事实、女主误判和冲突入口。
2. 先选择女主第一人称或双轨 POV；双轨时男方只能展示失控、错误追回、现实损失和认知变化，结局回到女主选择。
3. 前 1,500 字至少完成关系结构、核心伤口和两次反应变化；事件按功能使用 60—180、100—250、220—450 或 450—850 字预算。
4. 每章先保存 3—6 个事件地图，再按事件生成正文；事件地图记录功能、目标、冲突、行动、双方反应、信息/关系/资源/风险差、主动权变化、读者释放点和出口钩子。
5. 追悔分为“失控”与“理解”两个阶段；只有持续行动、承受损失和尊重女主边界才能进入真正追悔。
6. 读者爽点与女主是否复合解耦；女主重新取得选择权本身就是核心回报。
