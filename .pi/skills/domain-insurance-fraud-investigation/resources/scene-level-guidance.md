# Scene-Level Guidance（Round 9）

## 职业如何出现在 Scene
workflow / authority / evidence / procedural language / professional attention——不是术语列表。

## 职业细节承担
constraint（调档要双签）/ evidence（门禁记录成为 observable fact）/ decision（上报 vs 压住）/ status（结案时限）/ conflict（审批链施压）/ characterization（她先看什么）/ stakes（赔付率问责）。

## 检查
- 术语删除后行动、信息、冲突不变 → PROFESSIONAL_DETAIL_DECORATIVE；
- 同一场景连续大量术语阻断人物行动 → PROFESSIONAL_DENSITY_TOO_HIGH；
- 职业知识像培训手册 → PROFESSIONAL_EXPOSITION_DUMP；
- 职业女主的 POV 观察与普通人相同 → PROFESSIONAL_EXPERTISE_NOT_IN_POV。

## 示范
弱：“公司赔付率 KPI 导致调查受压。”
强：领导实际要求缩短调查、改变审批、延迟取证——制度产生行动后果。
