# Character Simulation

## 何时加载

人物卡和当前正史已稳定，且需要验证人物声音差异、动机可信度或高压反应时加载。

## 固定流程

1. 读取相关人物、关系、知识边界、目标、代价和当前场景合同。
2. 为每个角色分别回答：此人知道什么、想隐藏什么、此刻最怕什么、会采取什么行动、不会说什么。
3. 对比角色语言、选择和反应，标记声音同质化、知识越界、动机跳变和关系压力不足。
4. 输出局部修改任务；不得把模拟结果自动写入正史。

## 完成条件

报告包含证据、反事实测试和定向修改建议，且作者确认后才更新人物状态。
