# Scene Construction

## 场景五要素
goal（具体可验证）/ opposition（真正阻力）/ tactic（策略）/ turn（状态变化）/ state change + exit pressure。

## 目标必须具体
- 错误：“调查案件”“和丈夫谈谈”
- 正确：“让住院部护士确认，死亡证明是否在患者离院前录入”
- 正确：“逼丈夫明确回答，他什么时候知道保单被改过”
（SCENE_GOAL_TOO_ABSTRACT）

## Opposition 类型
person / institution / procedure / time / information / emotion / relationship / resource / self-protection。
阻力不能只是“对方不愿意说”（SCENE_WITHOUT_MEANINGFUL_OPPOSITION）。

## Tactic
direct-question / withhold / probe / trade / pressure / appeal / lie / deflect / invoke-authority / withdraw / observe / test / offer / threaten。
tactic 连续失败 → 换策略或付出代价离开（SCENE_TACTIC_NEVER_CHANGES）。

## Beat 是场景内部 dramaturgy
SceneBeat：actor / intent / actionType / action / response / informationChange / relationshipChange / emotionalShift / tacticChange / raisesQuestion / paysOffRef / speechIntent。
不要求每一段正文对应一个 beat。
