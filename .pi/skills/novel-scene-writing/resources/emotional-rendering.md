# Emotional Rendering

## 四层
felt emotion → shown behavior → decision effect → relationship effect。不要求每个情绪都有身体动作。

## 情绪兑现
对 high-value beat：情绪至少通过 action / choice / avoidance / attention / speech change / resource use / physical behavior / perception shift 之一表现。

## 检查
- 连续“她愤怒/她悲伤/她失望/她震惊”但行为无变化 → EMOTION_LABEL_WITHOUT_EFFECT；
- 强情绪没有任何 choice / tactic / relationship behavior / risk behavior → EMOTION_WITHOUT_DECISION_EFFECT；
- 动作后总是心理解释（“她这么做，是因为她终于意识到……”）→ ACTION_OVEREXPLAINED_BY_INTERIORITY。

## story-bearing emotion
“她害怕”不是“她很害怕”，而是：她没有立刻提交材料，先复制了一份到个人取证盘。
