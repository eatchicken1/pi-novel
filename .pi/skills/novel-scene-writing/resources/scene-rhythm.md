# Scene Rhythm

## 场景序列
Scene consequence → next scene motivation。三个 Scene 只是并排查资料 → SCENE_SEQUENCE_CAUSALLY_WEAK。

## 节奏
Chapter 不是几个相同 intensity 的 Scene。连续 4 个两人坐着谈话 / 连续 5 个查资料 → RHYTHM_MONOTONY。

## Recovery 不是 filler
恢复场景应吸收代价 / 做选择 / 改变关系 / 制造 false security；没有新状态 → RECOVERY_WITHOUT_NEW_STATE。

## 触发器
关键 turn 不要过度依赖电话 / 短信 / 敲门 / 突然出现（TRANSITION_TRIGGER_REPETITION）。

## 开场 / 结尾
- 开场迅速建立 current task / tension / abnormality，不要天气→走路→坐下→点菜→寒暄（SCENE_OPENING_INERT）；
- 场景结尾留下 decision / cost / new question / changed relationship / changed strategy / unavoidable next action。
