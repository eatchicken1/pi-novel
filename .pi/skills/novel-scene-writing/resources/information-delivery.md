# Information Delivery

## 投放方式
document / dialogue / observation / professional procedure / conflict / mistake / absence / contradiction / consequence / memory / public information。
悬疑小说最容易写成材料说明会。

## 诊断
- INFORMATION_DUMP：连续大段传资料，无 objective / opposition / decision；
- PROFESSIONAL_EXPOSITION_DUMP：职业知识像培训手册；
- SOCIAL_COMMENTARY_DUMP：社会议题像公众号评论；
- MYSTERY_EXPLANATION_DUMP：线索意义被作者立即解释完。

## Clue
- observable fact 与 interpretation 分开；核心谜底线索保留重新解释空间；
- 禁止“这就是关键证据”（CLUE_DELIVERY_TOO_EXPLICIT）；
- 支持 reader knows > heroine / heroine knows > reader / reader == heroine（复用 audience knowledge，不要任何信息都必须藏）。

## InformationDeliveryPlan
informationUnit / readerBefore / heroineBefore / deliveryMode / surfacePurpose / immediateInterpretation / hiddenImplication / strategicEffect（仅重要信息）。
