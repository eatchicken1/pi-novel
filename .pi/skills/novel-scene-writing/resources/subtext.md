# Subtext

## surfaceMeaning vs underlyingIntent
只用于重要关系场景。例：
“今天几点回来？”
surface：问时间。
underlying：确认你是不是又去了公司。

## 行为证据
报告声称有潜台词，但 action / omission / wording 没有任何证据 → SUBTEXT_WITHOUT_BEHAVIOR。
subtext 声明写在 SceneDesign.subtext（author-private，reader-sim 不读取），兑现证据在 SceneSemanticReport.evidence（正文锚点）。

## 不要
- 每句都强制 subtext；
- 为了“有潜台词”让所有人物答非所问（目标是 character-appropriate communication）。
