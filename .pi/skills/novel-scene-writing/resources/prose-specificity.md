# Prose Specificity

## 具体细节
真实感来自 specific concrete detail，但道具不能堆（DETAIL_WITHOUT_NARRATIVE_FUNCTION）。

## 反装饰
大量比喻 / 环境抒情 / 情绪修饰，没有增强 character / tension / meaning / voice → PROSE_DECORATIVE_WITHOUT_FUNCTION。
比喻检查：MIXED_METAPHOR / REPEATED_METAPHOR_DOMAIN / CLICHE_METAPHOR（semantic warning，不硬禁）。

## 反模板
AI 式“高级克制”：一句。又一句。她没有说话。他也没有。风吹进来。→ MINIMALIST_FRAGMENT_OVERUSE（不 hard fail）。

## 场景地点
Location 应影响 privacy / power / movement / available actions / social pressure；可随意替换 → SETTING_DECORATIVE（仅重要场景）。
