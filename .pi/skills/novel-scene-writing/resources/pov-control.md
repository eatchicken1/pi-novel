# POV Control

## Observation ≠ Interpretation ≠ Truth
Narrator statement 不能自动等于 author truth；POV 可以错误判断。

## 知识泄漏
第一人称 narrator 不得知道自己无法知道的信息（POV_KNOWLEDGE_LEAK）：
“她不知道的是，丈夫已经签了字”“他心里想……”在 heroine-first-person 中都是泄漏。

## 内心声音
第一人称内心不能只是解释剧情，应包含：selection of attention / judgment / professional categorization / self-deception / memory trigger / avoidance / value conflict / controlled emotion。
