# Genre Promise（女性社会派悬疑）

本类型的承诺：悬疑真相由社会结构生成，个人命运是结构压力的显影。

- 四层真相：event（发生了什么）/ actor（谁做了什么）/ system（为什么能长期发生）/ personal（女主原先误解了什么）；
- 社会问题不是背景标签：机制 → 事件 → 阻力 → 信息受限 → 选择 → 代价；
- 女主是结构中的行动者，职业身份给她通道也给她代价；
- 婚姻是结构之一：长期模式放大冲突，破裂与案件互为因果；
- 结局允许案件解决、制度未变。

反承诺：普通推理 + 附议题；女主金句封神；最后都是某个坏男人干的；抓到坏人 = 问题解决。
