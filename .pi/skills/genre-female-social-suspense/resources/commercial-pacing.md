# Commercial Pacing（中篇）

开篇进入异常的速度要快（前两章出现不可逆或成本）；前段需要不可逆 hook；中段需要碰撞与重释（midpoint reframe）；后段是证明 + 关系收束；每章结尾要有向前的压力（问题/决定/新证据/关系变化/威胁/成本/矛盾/不可逆动作）。

诊断：OPENING_DELAYED / EARLY_STAKES_WEAK / MIDPOINT_WITHOUT_REFRAME / LATE_EXPOSITION_DUMP / ENDING_AFTERSHOCK_MISSING / FORWARD_PRESSURE_WEAK。阈值宽松，不要每章 cliffhanger。
