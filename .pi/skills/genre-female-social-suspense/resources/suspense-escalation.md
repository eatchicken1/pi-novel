# Suspense Escalation

悬疑不是线索的累加。每次核心推进最好改变至少一种：hypothesis / suspect / stakes / personal risk / relationship interpretation / institutional interpretation / time pressure / evidence reliability。

连续只加线索不改解释 → SUSPENSE_INFORMATION_WITHOUT_REINTERPRETATION；核心案件推进很久风险无变化 → SUSPENSE_STAKES_STAGNANT；中篇没有可推翻的中间解释 → FALSE_MODEL_MISSING（不要硬性要求红鲱鱼，但需要 false model）。
