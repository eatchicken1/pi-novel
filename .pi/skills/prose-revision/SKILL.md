# Prose Revision

## 何时加载

结构和连续性已稳定，需要改善声音、对白、节奏、意象或表面错误时加载。

## 固定流程

1. 读取任务相关上下文和当前草稿。
2. 先保留视角、事实、动机、信息顺序和场景功能。
3. 按结构、场景、段落、句子、校对顺序修改；一次只解决一层问题。
4. 使用 `save_chapter_draft` 保存新 revision。
5. 事实或时间线发生变化时重新执行连续性检查。

## 约束

避免解释所有情绪、统一句式、连续总结、模板化升华和可识别的在世作者风格。修改建议和作者确认事实必须分开。

## 完成条件

新草稿可追溯，未引入未记录的事实变化，且必要时有新报告绑定新版本。
