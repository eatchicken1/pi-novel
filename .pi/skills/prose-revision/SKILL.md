# Prose Revision

## 固定流程

1. 用 `read_story_context` 读取风格指南、章节目标、人物状态和需要修改的草稿。
2. 先列出保留项：视角、时态、事实、动机、伏笔和章节功能。
3. 再处理冗余、句式、对白、感官细节、段落节奏和 AI 腔。
4. 修改结果先保存为新的 `chapter-draft`，不要直接覆盖定稿。
5. 修改涉及事实、事件顺序或人物状态时，重新调用 `check_continuity`。

## 约束

- 不模仿在世作者的独特措辞或可识别段落。
- 不用“更优美”掩盖逻辑、动机和信息顺序问题。
- 说明重大改写的目的和副作用，让用户可以逐项审阅。

## 完成条件

- 草稿与定稿版本边界清晰。
- 语言修订没有引入未记录的事实变化。
