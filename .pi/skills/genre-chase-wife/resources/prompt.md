# 追妻文创作约束与方法

## 1. 开场

从 `cold-conflict`、`result-first`、`exit-in-progress`、`quiet-dislocation` 中选择一种。开场引言不是摘要，必须让读者立刻看见关系位置、异常、错误判断或即将爆发的冲突。`quiet-dislocation` 才要求 80—180 字引言；其他模式允许用更短的动作或结果切入，但 250 字内必须出现可见冲突。

## 2. 女主留下的逻辑

在伤害发生前写清：

- `emotionalReason`：她仍然在乎什么；
- `materialReason`：她承担什么现实成本；
- `socialReason`：关系、家庭、工作或公众压力如何约束她；
- `falseBelief`：她当时相信的错误解释；
- `sustainingEvidence`：为什么她没有立刻离开；
- `breakingThreshold`：这一次为什么成为临界点。

不能用“她还爱他”解释所有停留，也不能让女主因为剧情需要反复原谅同一种伤害。

## 3. 主动权与事件差

主动权至少追踪 epistemic、relational、material、social、future 五个维度，每个维度 0—4 级。事件必须改变至少两项信息、关系、资源、风险、主动权、现实后果或伏笔状态；一个动作不能被重复计为多个变化。退出阶梯应表现为：微撤回 → 边界试探 → 资源或安排改变 → 明确决定 → 不可逆退出。

## 4. 双轨追妻

女主轨：受伤、识别、撤回、试探、退出、重建、最终边界。

男方轨：理所当然、失去控制、错误追回、现实后果、具体认知、尊重或失败。男方视角只展示可观察的损失、错误、成本和行为，不替女主解释感受，不重写正史。

## 5. 节奏预算

事件长度使用 `flash=60—180`、`bridge=100—250`、`standard=220—450`、`anchor=450—850`。取消预约、删除联系人、收到信息和转场通常用 flash/bridge；抓奸、对质、公开纠正和最终拒绝才用 anchor。相同伤害机制连续不得超过两次；连续两段纯心理解释后必须出现动作、对话、证据或选择；回忆必须重新解释当前伤害并在 300 字内推动行动。

## 6. 关系账本

`save_harm_ledger` 记录伤害类别、受害影响、双方当时的信念、严重程度、女主和男方是否识别、是否可修复。`save_repair_ledger` 记录修复指向、行动、男方成本、女主收益、是否越界、是否被接受和可信度。`check_chase_wife_ending_eligibility` 负责判断修复是否足以支持 `no-reunion`、`earned-reunion` 或 `open-ending`，模型不得自行宣布“值得复合”。

## 7. 读者与审查

Reader/Review 必须针对当前定稿草稿提交字符锚点，指出投入下降、预测、困惑、可信度断裂、结构问题、场景问题、人物问题和优先级。审查者不能只复述计划；正文没有证据就不能声称事件成立。
