# 批注式参考拆解方法

这类参考文不应只总结“发生了什么”，而要拆成可以执行的事件链。每个事件都回答：

```text
事件发生了什么？
这一段为什么必须存在？
谁主动、谁被迫反应？
双方分别知道什么？读者比谁多知道什么？
女主的情绪和身体反应如何变化？
它改变了什么资源、关系、知识或风险？
它承接了什么，下一段要钩住什么？
```

## 开篇引言的拆法

批注案例的开头不是背景介绍，而是一个短引言同时完成四件事：

1. 直接交代异常事实，例如第三人怀孕、反复流产、被隐瞒或被优先照顾；
2. 交代女主与关键人物的关系位置；
3. 让女主先按自己的认知替对方辩护，形成信息差；
4. 在引言结束时把女主送进一个马上会揭露真相的具体场景。

引言之后必须立刻进入冲突场景。不要先写天气、城市、成长经历、人物简历或世界观说明。

## 微事件公式

参考案例中最有效的单元可以抽象成：

```text
具体事件
→ 女主当下反应
→ 对立人物的反应或辩解
→ 女主态度再变化
→ 信息、关系、资源或风险发生变化
→ 读者释放点 / 下一钩子
```

对立人物的对话常用“提出方案 → 被反驳 → 换理由再提出 → 再次反驳 → 暂时妥协或暴露偏爱”的拉扯。它比一次性解释“他们很相爱”更能让关系在现场自己显形。

## 参考案例的阶段拆法

对提供的批注样本《岁岁无君亦无晴》，不复用人物和事件，只提取其结构机制：

| 阶段 | 事件功能 | 情绪与节奏任务 |
| --- | --- | --- |
| 引言与事件 1—3 | 医疗场景抛出信息差，女主被支开后听见秘密；补齐三人关系和男方的多重身份 | 期待直接坠入惊愕；让读者知道女主暂时不知道的真相 |
| 事件 4—8 | 三人回到表面关系，男方用体面借口继续照顾第三人；地点、座位和动作泄露熟悉程度 | 女主强撑体面，读者从细节中确认背叛不是偶然 |
| 事件 9—12 | 回忆女主曾经救过第三人，再用物件和一次小反击切回现在 | 先给女主高光，再把恩情反转成更重的伤害；每段都产生一点释放 |
| 事件 13—18 | 男方用职业理由离开，女主主动跟踪并撞破；男方在情浓时被发现，公开承认关系起点 | 主动权转给女主；通过男方保护第三人的动作把情绪推到全篇高点 |
| 事件 19—24 | 女主提出结束，男方仍替第三人辩护；女主清空生活并离开，男方出现迟来的不安 | 付费卡点不是哭，而是女主完成不可逆退出；男方的追悔先表现为失控 |
| 事件 25—30 | 婚礼/公共场合集中曝光证据，旁观者替读者说出判断；男方回家发现女主彻底消失，第三人继续索取 | 私人伤害转成社会后果；男方从自信转入恐慌和认知修正 |
| 事件 31—34 | 时间跳跃展示女主已建立稳定生活；旧关系重逢，孩子和新伴侣形成新秩序对照；女主处理最后纠缠 | 爽点来自新生活的完整，不来自男方是否被原谅；结尾把选择权留在女主手里 |

## 情绪标注方式

不要只写“女主很伤心”。每个事件至少写四层：

```text
外部刺激：看见、听见、收到、被要求或被阻止的具体事实
心理判断：她如何重新解释这件事
身体反应：停顿、失手、胃部、呼吸、手指、视线或动作变化
行为选择：继续伪装、试探、反击、取证、退出或建立新秩序
```

男方和第三人的情绪也要通过行为展示。尤其要区分男方的“失去控制”与“真正理解伤害”，前者不能直接当作悔悟。

## 节奏硬约束

- 开篇引言控制在 80—180 字，之后 250 字内出现第一次可见冲突；
- 事件按 `flash=60—180`、`bridge=100—250`、`standard=220—450`、`anchor=450—850` 分配长度，不能把所有事件强行写成同一体积；
- 前 1,500 字完成关系结构、核心伤口和第一次女主反应升级；
- 3,000—4,000 字前完成证据揭露和不可逆退出；
- 6,000—8,000 字进入公开后果、关系爆炸或现实代价；
- 每个事件至少改变信息、关系、资源、风险中的两项，或产生不可逆行动、主动权提升、现实后果或铺垫回收；
- 正文不输出“事件 1”“情绪分析”“读者释放点”等拆解标签，标签只存在于事件地图和审查报告。
