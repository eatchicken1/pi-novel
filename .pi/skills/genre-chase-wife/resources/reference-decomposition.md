# 批注式参考文拆解方法

参考文不能只总结“发生了什么”，要拆成可以执行和验证的事件链。每个事件回答：

```text
发生了什么具体事实？
为什么这一段必须存在？
谁主动、谁被迫反应？
双方分别知道什么，读者比谁多知道什么？
女主的情绪和身体反应如何变化？
信息、关系、资源、知识或风险改变了什么？
它承接哪个铺垫，又把读者钩向哪里？
```

## 开篇拆解

开篇不是背景介绍，而是用一个短段同时完成：

1. 抛出异常事实或关系位置；
2. 交代女主与关键人物的现实关系；
3. 让女主先按自己的认知解释异常，制造信息差；
4. 在引言结尾把她推进即将爆发的冲突。

开篇之后立即进入冲突，不先写天气、城市、成长经历、人物简历或世界观说明。

## 微事件拆解

```text
具体事实
→ 女主当下反应
→ 对立人物反应或辩解
→ 女主判断改变
→ 信息 / 关系 / 资源 / 风险发生变化
→ 读者释放点或下一钩子
```

对话可使用“提出方案 → 被反驳 → 换理由 → 再次反驳 → 暂时妥协或暴露偏袒”的拉扯，但每轮必须改变关系，不要重复同一句争吵。

## 长篇阶段

将参考文拆成机制，不复制人物和事件：

| 阶段 | 要提取的机制 |
| --- | --- |
| 引言与前段 | 异常事实、关系位置、第一处信息差、首个伤口 |
| 伤害累积 | 不同伤害机制如何升级，女主何时开始主动撤回 |
| 退出阶段 | 取消安排、保留证据、撤回资源、设置边界、不可逆离开 |
| 追妻阶段 | 男方失去什么、做错什么、承担什么现实后果 |
| 新生活与结局 | 女主建立什么新秩序，最终选择是否仍属于女主 |

拆解稿中的“场景、事件、情绪、功能”是规划信息，不能原样输出到正文。每一段都要能对应到事件角色、状态差和正文证据。
