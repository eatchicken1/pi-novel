# 追妻文情绪曲线

情绪事件使用以下链条：

```text
外部刺激 → 角色判断 → 身体反应 → 行动选择 → 新状态
```

禁止使用“很伤心—更加伤心—彻底心死”作为完整曲线。每次情绪升级至少改变一项现实条件：承诺、时间、身体、金钱、名誉、证据、家庭压力或选择权。

女主曲线：受伤、识别、撤回、试探、决定、退出、重建、最终边界。男方曲线：理所当然、失去控制、错误追回、现实后果、具体认知、尊重或失败。两条曲线可以交叉，但男方的认知不能替代女主的选择。

每个事件都要写清：情绪发生前的状态、情绪转折点、转折后的可见行为，以及该行为如何改变下一事件。没有行为、证据、对白、资源变化或关系变化的情绪段落，应合并或删除。
