# 追妻文情绪曲线

采用“累积伤口—停止索取—行动释放—迟来追悔—平静收束”，而不是一味提高争吵音量。每次升级要改变至少一项现实条件：承诺、时间、身体、钱、名誉、证据、家庭或选择权。

每个情绪事件按以下链条设计：

```text
外部刺激 → 角色判断 → 身体反应 → 行为选择 → 新信息/新状态
```

“很伤心、更加伤心、彻底心死”不是情绪曲线。若情绪没有带来动作、对话、证据、资源变化或关系变化，事件应合并或删除。男方情绪必须通过失去控制、错误行动、现实损失和具体认知表现，不能只写内心总结。

虐点看损失的不可逆程度；爽点看女主是否重新掌握处置权。男方的悔恨是读者的余波，不是女主必须接收的礼物。
