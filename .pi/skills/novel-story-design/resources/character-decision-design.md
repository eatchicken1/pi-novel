# Character Decision Design

## 角色不是性格标签
角色是“在某种信息和压力下会做什么决定”。CharacterDecisionPattern：situation / currentGoal / currentBelief / hiddenFear / perceivedOptions / preferredStrategy / avoidedChoice / decisionThreshold / likelyCost / relevantRefs。

## 女主决策链
关键 turning point 必须能解释：Information + Value + Constraint + Emotion + Resource → Decision。
不能“剧情需要她突然决定离婚”→ TURNING_POINT_WITHOUT_DECISION_CAUSE。

## 男方独立目标
男方必须有 independentGoal（保护家族企业 / 保住控制权 / 阻止父亲承担责任 / 维护交易 / 保护女儿 / 保住职业身份）。
不能从中段开始唯一目标就是“追回女主”→ SPOUSE_PLOT_COLLAPSES_TO_PURSUIT。

## 配角
重要配角至少应有：goal / information / leverage / cost。他们进入事件是因为自己的利益，不是作者需要他递线索（复用 SupportingCharacterFunction）。
