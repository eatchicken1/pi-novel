# Architecture Comparison

## 候选必须真正不同
2-3 个 architecture candidate 需要在以下维度拉开差距：reveal timing / false model duration / marriage rupture timing / professional dilemma timing / irreversible exit timing / climax structure / ending shape。
只有 movement 名称不同 → ARCHITECTURE_CANDIDATES_TOO_SIMILAR。

## 比较维度
causalStrength / mysteryFairnessPotential / genrePromise / heroineAgency / relationshipIntegration / professionalNecessity / socialDepth / midLengthCompression / collisionQuality / climaxConvergence / endingEarnedness / genericRisk。
不使用 numerical scores；输出 strong / workable / risky + 具体原因。

## 版本与权威
- 候选是 proposal 层（work/authoring/architecture-candidates.json）；
- 正式架构只有一份（outline/story-architecture.json）；
- 修订走版本化 lineage（outline/story-architecture-vN.json + work/authoring/architecture-lineage.json），不覆盖历史。
