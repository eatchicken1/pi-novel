# Ending Backward Design

## 用途
在完整 architecture 之前先确定故事最终必须结算什么，再反向约束前文。

## EndingArchitecture 要素
mysteryResolution / heroineResolution / marriageResolution / chaseResolution / professionalResolution / socialResolution / costDistribution / unresolvedResidue / finalImageOrState / requiredPrerequisites / climaxChoice。

## Backward 链条
Ending ← Climax ← Required Choices ← Required Knowledge ← Required Costs ← Required Setup。

## Prerequisite 回推
每一个重大 ending payoff 必须能回推“它之前需要什么”。例如：
丈夫最终公开承担家族责任，需要：earlier belief → pressure → failed pursuit → real consequence → recognition → opportunity to choose。
前面不存在这些 → ENDING_PAYOFF_UNEARNED。

## 结局不是解释
- 真相揭露 → 男主认错 → END 是禁止的收尾；
- 至少考虑 professional aftermath、social residue、marriage logistics、heroine future state、cost distribution。
