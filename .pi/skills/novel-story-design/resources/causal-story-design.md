# Causal Story Design

## Anchor Spine
不要直接生成 30-60 个事件。先设计全书不可替代的 8-16 个核心事件（NarrativeAnchor），覆盖：
opening disturbance / first investigation commitment / first cross-domain collision / false model reinforcement / major contradiction / professional-personal dilemma / relationship boundary recognition / midpoint reframe / cost escalation / irreversible exit / truth compression / climax choice / aftermath settlement。

Anchor 不是第二事件 authority；最终引用 Unified Event IDs。

## Causal Link 语义
StoryCausalLink：causes / enables / blocks / reveals / escalates / forces-choice / pays-off / reinterprets（coincidence 为自报风险）。

## Filler 判定
移除该 event 后：causal graph 是否变化 / information 是否变化 / decision 是否变化 / cost 是否变化 / relationship 是否变化 / setup-payoff 是否断裂。全部不变 → EVENT_FILLER_RISK。

## Bridge 事件
每个 bridge 至少承担：setup / complication / cost / pressure / recovery / re-interpretation / decision-preparation 之一。禁止“因为需要凑章节，再查一次资料”。

## 巧合
EVENT_DEPENDS_ON_COINCIDENCE：因果 link 标注 coincidence 时给出；巧合不能承担因果。
