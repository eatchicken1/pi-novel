# Voice Revision

## 不是换高级词
重点是：sentence rhythm / observation selection / emotional distance / dialogue compression / narrator attitude。

## 与 Voice Profile 对齐
Voice Profile 是设计目标，Voice Fingerprint 是当前 prose 的表现（continuity/reports/chapter-NNN-voice.json）。
- 显著偏离 → VOICE_DRIFT（如女主突然从克制现实主义变成网络爽文金句）；
- 命中 profile.avoidPatterns → 修订回 profile。

## 反模板
- 装饰性比喻无功能 → 删或赋予功能；
- 极端短句模板 → 恢复句长变化；
- 情绪标签 → 换成行为/选择。
