# Exposition Revision

## 方向
把“传资料”改成“要资料”：character objective + opposition + decision 包裹信息。

## 信息投放改写
- 材料说明会 → 让角色在 conflict 中获取信息（mistake / absence / contradiction / consequence）；
- 职业手册腔 → 职业细节承担剧情机制；
- 社会评论腔 → 制度通过 procedure / power asymmetry / cost allocation 表现；
- 线索即解释 → observable fact 与 interpretation 分开，保留重新解释空间。
