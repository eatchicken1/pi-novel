# Scene Revision

## 范围优先
默认 Beat → Scene → Event → Chapter。对话不自然不得整章重写（revise_chapter goal.scope="scene" + sceneIds）。

## Scene 修订目标
- tighten-scene：删掉无功能 beat；
- strengthen-opposition：把“对方不愿意说”换成制度/时间/资源阻力；
- improve-scene-turn：给 high-value 场景补 turn；
- dramatize-professional-detail：让职业细节承担 constraint/evidence/decision。

## 修订后重跑
scene 修订 → plan_chapter（scene designs 更新）→ draft → diagnose。scene semantic report 的 evidence 必须重新绑定正文。
