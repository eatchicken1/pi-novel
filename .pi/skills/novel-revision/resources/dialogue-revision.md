# Dialogue Revision

## 目标
character-appropriate communication，不是“有潜台词所以答非所问”。

## 修改点
- 共享知识 exposition → 删或改成信息差；
- 事务性 Q/A → 插入 deflect / counter-question / silence / action-response；
- 直白主题句 → 通过行为与 wording 表达；
- 角色声音同质 → 按句长/直接度/职业词汇/回避方式区分（fix-dialogue-specificity）。

## 禁止
为“更有张力”故意让所有人物答非所问。
